# Bingoals Mobile

Flutter mobile app for Bingoals - a gamified annual goal tracking application with a bingo grid interface.

## Setup

```bash
flutter pub get
flutter run
```

## Tech Stack

- Flutter 3.38+
- Riverpod (state management)
- Go Router (navigation)
- Dio (HTTP)
- Hive (local cache)

See `/docs` for detailed documentation.
